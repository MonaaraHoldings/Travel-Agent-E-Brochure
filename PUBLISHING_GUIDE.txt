MONAARA LEISURE WEBSITE — PUBLISHING GUIDE

1. Extract this ZIP.
2. Open the folder: Monaara_Leisure_Approved_Trade_Brochure
3. Upload the CONTENTS of that folder (not the outer folder itself) to the root of your existing GitHub repository:
   https://github.com/dsgavinkodithuwakku-web/Monaara-E-Brochure
4. Ensure index.html is at the repository root and upload the assets/ and downloads/ folders.
5. Commit the changes. If prompted, choose to replace the existing files.
6. Wait for GitHub Pages to deploy, then hard-refresh the live site (Ctrl+F5).
